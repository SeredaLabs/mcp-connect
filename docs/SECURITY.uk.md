# 🛡️ Безпека

🌐 [English](../SECURITY.md) · **Українська**

[← Огляд](INSTALL.uk.md) · [Авторизація](AUTHENTICATION.uk.md) · [Безпека](SECURITY.uk.md) · [Збирання](BUILD.uk.md)

Повідомляйте про вразливості приватно через **[Security → Report a vulnerability](https://github.com/SeredaLabs/mcp-connect/security/advisories/new)**. Не додавайте справжні облікові дані, бізнес-дані, локальні профілі чи приватні адреси серверів у публічні Issues.

MCP Connect зберігає секрети в захищеному сховищі ОС. Параметри профілю й реєстрації клієнта не містять пароля, токена чи API-ключа. Секрети прив'язані до точної адреси сервера й способу авторизації. Старі записи без прив'язки потребують повторного введення. Непідтримуване або заблоковане сховище спричиняє помилку без переходу до відкритого текстового зберігання.

Перевірка HTTPS-сертифікатів завжди ввімкнена. Перенаправлення й запити до іншого джерела блокуються. Дозволені заголовки API-ключів обмежені визначеним списком; значення токенів із керувальними символами відхиляються. Діагностичні помилки не містять секретів і тіл відповідей сервера. Адаптер не повторює бізнес-виклики з невідомим результатом після обриву з'єднання.

Клієнтські адаптери перевіряють належність запису перед заміною чи видаленням. Claude Desktop зберігає сторонні JSON-поля; ChatGPT перевіряє записи належності, межі шляху встановлення та симлінки керованих каталогів. Помилка одного клієнта не скасовує успішні незалежні інтеграції. Disconnect зберігає вимкнений стан профілю перед очищенням, тому його помилка не дозволяє нових запусків адаптера. Докладніше про ці перевірки та їхні межі — [архітектура інтеграцій](INTEGRATIONS.uk.md).

Межі доступу визначають обліковий запис ОС, дозволи на інструменти в AI-клієнті та права на віддаленому сервері. Утиліта не є ізольованим середовищем, проксі лише для читання чи службою надання прав. Процес, якому дозволено використовувати підключення, може викликати інструменти в межах прав вашого серверного облікового запису. Щоб припинити вже запущені процеси адаптера, завершіть відповідні клієнтські сесії.

Виправлення отримує лише останній випуск. Пакунки Preview не мають підпису видавця чи нотаризації. macOS-програма має лише ad-hoc підпис; це не підпис Developer ID. Автоматичні перевірки та сканування відомих вразливостей не є сертифікацією безпеки.

Перевірка оновлень звертається лише до публічних випусків GitHub без профілів MCP чи облікових даних. Завантаження установника потребує збігу розміру та SHA-256, HTTPS і дозволеного хоста GitHub. Установлення запускається явною дією та проходить системне підтвердження, якщо його вимагає ОС. Контрольна сума не є незалежним підписом видавця. Докладніше — [оновлення](UPDATES.uk.md).
