## Оновлення до 0.4.13

[0.4.13 Preview](https://github.com/SeredaLabs/mcp-connect/releases/tag/v0.4.13) зберігає наявні профілі, облікові дані та ID реєстрацій. Рефакторинг адаптерів не потребує ручного перенесення даних чи створення підключень заново. Перевірено, що оновлювач 0.4.12 виявляє опублікований випуск 0.4.13. Якщо шлях установленої програми не змінився, виправляти реєстрації не потрібно; після зміни шляху натисніть **Save & Apply**.

## 🖥️ У програмі

Починаючи з **0.4.11**, MCP Connect один раз під час запуску перевіряє публічні випуски GitHub. Якщо доступна новіша версія, у бічній панелі з’являється синя кнопка **Update · v…**. Перевірку також можна запустити через **ⓘ → About MCP Connect → Check for updates**.

Кнопка оновлення завантажує установник для ОС та архітектури програми. Перед запуском повний файл має збігтися з розміром і SHA-256, опублікованими GitHub. Заміною файлів і системним підтвердженням займається звичайний установник. Профілі, секрети й реєстрації клієнтів залишаються на місці.

Перед установленням закрийте активні сесії адаптера в AI-клієнтах, після — перезапустіть клієнти. Нова ad-hoc підписана збірка macOS може повторно попросити дозвіл Keychain. У Linux використовується системне підтвердження (`pkexec`) та apt; якщо їх немає, встановіть перевірений `.deb` вручну через менеджер пакунків. Якщо запуск не вдався, програма покаже шлях до завантаженого файла.

**Cancel update** скасовує завантаження та видаляє неповний файл. Ця дія не скасовує вже запущений установник.

Версії **0.4.10 і старіші** потрібно один раз оновити вручну до 0.4.11 або новішої, щоб отримати цю можливість.

## ⌨️ Через термінал

| Система | Команда для стандартного встановлення |
|---|---|
| macOS | `"/Applications/MCP Connect.app/Contents/MacOS/mcp-connect" update` |
| Windows PowerShell | `& "$env:LOCALAPPDATA\Programs\MCP Connect\mcp-connect.exe" update` |
| Linux | `mcp-connect update` |

Додайте **`--check`**, щоб перевірити наявність версії без завантаження й установлення. **`--download`** лише збереже перевірений установник і покаже його шлях. Ці команди не читають секрети зі сховища й не звертаються до вашого MCP-сервера. Якщо Windows-програму встановлено в інший каталог, використайте фактичний шлях до `.exe`.

## 📦 Портативні копії

Портативна копія перевіряє оновлення, але не переноситься й не перезаписується автоматично. Завантажте новий portable-архів зі [сторінки завантаження](https://seredalabs.github.io/mcp-connect/), закрийте утиліту та AI-клієнти й замініть програму в тому самому постійному каталозі. Після зміни шляху натисніть **Save & Apply**, щоб виправити реєстрації.

`update --download` явно завантажує установник; ця команда не замінює портативну копію на місці.

## 🔐 Мережа й довіра

Вимкніть **Check for updates on launch** у вікні About, щоб зупинити автоматичні перевірки. Ручна перевірка залишиться доступною. Налаштування зберігається локально у `updates.json` поруч із профілями. Перевірені завантаження зберігаються в кеші користувача ОС у `MCP Connect/updates`; неповні й скасовані файли видаляються.

Перевірка звертається до публічного API GitHub і передає версію програми в User-Agent. GitHub отримує звичайну мережеву інформацію, зокрема IP-адресу. Назви підключень, адреси MCP, облікові та бізнес-дані не передаються. Окремої фонової служби, телеметрії й автоматичного встановлення немає. Перевірка враховує опубліковані Preview-випуски.

Дозволені лише HTTPS-пакунки цього GitHub-репозиторію та визначені хости завантаження GitHub. Контрольна сума перевіряє цілісність за метаданими GitHub; це **не** незалежний підпис видавця. Установники macOS PKG і Windows залишаються без підпису видавця. Відсутність мережі чи обмеження запитів GitHub не заважає роботі утиліти.
