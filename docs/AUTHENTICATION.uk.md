Виберіть спосіб, який підтримує ваш MCP-сервер. Утиліта не вмикає способи авторизації на самому сервері.

| Спосіб | Що ввести | Що надсилається серверу |
|---|---|---|
| Логін і пароль | Логін та прихований пароль | HTTP Basic через HTTPS |
| Bearer token | Прихований токен без префікса `Bearer` | `Authorization: Bearer …` |
| API key | Вибір заголовка та прихований ключ | `X-API-Key`, `Api-Key` або `X-Auth-Token` |

## 🔐 Зберігання

Секрети зберігаються в macOS Keychain, Windows Credential Manager або Linux Secret Service. Профілі містять параметри підключення, а реєстрація клієнта — шлях до адаптера та ID профілю. Секрети не копіюються в конфігурацію клієнтів.

Якщо сховище недоступне або заблоковане, утиліта повертає помилку. Запасного зберігання відкритим текстом немає. Повний запис секрету разом із прив'язкою до сервера обмежений **2560 байтами** для сумісності з Windows. Дуже довгі токени можуть не вміститися.

## ✏️ Редагування підключення

Порожні поля повторно використовують збережений секрет лише за незмінних адреси, способу авторизації та заголовка API-ключа. Якщо ці параметри змінилися, введіть секрет заново. Старі записи без прив'язки до сервера також потребують повторного введення й збереження.

Зміна лише назви профілю чи вибору клієнтів застосовується через **Save & Apply** без читання секретів зі сховища та звернення до MCP-сервера. Зміни адреси чи облікових даних перевіряються перед збереженням.

На macOS дозвіл Keychain залежить від виконуваного файла та його підпису. Нова ad-hoc підписана збірка може знову попросити дозвіл.

## 🔑 Токени й дозволи

Токени та ключі вводяться вручну. OAuth-вхід, автоматичне оновлення токенів і довільні заголовки не реалізовані.

Відповідь `401` означає помилку авторизації, `403` — відмову в доступі. Перевірте строк дії, права на сервері й область доступу токена. Утиліта не може надати серверні права.

**Disconnect** спочатку вимикає профіль, потім прибирає локальні реєстрації та залишає секрет. Якщо очищення не вдалося, профіль залишається вимкненим, а дію можна повторити. **Delete** також видаляє профіль і секрет. Перезапустіть клієнти, щоб завершити вже відкриті сесії адаптера.
