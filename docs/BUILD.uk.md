# 🛠️ Збирання MCP Connect

🌐 [English](BUILD.md) · **Українська**

[← Огляд](INSTALL.uk.md) · [Авторизація](AUTHENTICATION.uk.md) · [Безпека](SECURITY.uk.md) · [Збирання](BUILD.uk.md)

Збирайте пакунок для відповідної ОС із версіями залежностей, зафіксованими в `go.mod` і `go.sum`.

## 📋 Вимоги

| Платформа | Інструменти |
|---|---|
| macOS | Go 1.27.2+, Xcode Command Line Tools |
| Windows AMD64 | Go 1.27.2+, Git Bash, MSYS2 UCRT64 GCC |
| Windows ARM64 | Go 1.27.2+, Git Bash, MSYS2 CLANGARM64 clang |
| Ubuntu 24.04 | Go 1.27.2+, компілятор C, бібліотеки для графічного інтерфейсу |

Для Windows потрібен `7z` або `zip` у PATH. Установіть `CC` у повний шлях до відповідного компілятора MSYS2, щоб випадково не використати інший компілятор із PATH.

Для Ubuntu встановіть:

```sh
sudo apt-get install build-essential dpkg-dev libgl1-mesa-dev libegl1-mesa-dev xorg-dev libxkbcommon-dev libwayland-dev wayland-protocols
```

## 🛠️ Збирання

```sh
bash scripts/build.sh
```

Пакунки зберігаються в `dist/`. До них входять виконуваний файл або `.app`, українська інструкція, ліцензія програми та повідомлення про ліцензії залежностей.

[Процес збирання](https://github.com/SeredaLabs/mcp-connect/actions/workflows/build.yml) збирає шість цільових платформ на відповідних ОС: для кожної створює portable-архів та установник, загалом 12 пакунків. Також перевіряє цілісність залежностей, статичний аналіз та відомі вразливості. Він не виконує підписування видавцем чи нотаризацію.

Пакування Windows створює вбудовану іконку через `go-winres v0.3.3`. Цей інструмент завантажується Go лише для збирання й не входить до програми.

## 📦 Установники

Після `bash scripts/build.sh` виконайте `bash scripts/package-installer.sh` на відповідній ОС. macOS використовує вбудовані `pkgbuild` і `productbuild`, Linux — `dpkg-deb`, Windows — Inno Setup 7.1.0 (задайте `ISCC` як шлях до `ISCC.exe` або додайте `iscc` у PATH). Компілятор Windows потрібен лише для збирання. CI завантажує офіційний випуск і перевіряє зафіксований SHA-256.

CI перевіряє встановлення та командний режим програми на всіх шести платформах, а також видалення й очищення ярликів на Windows/Linux. Це не підтверджує графічний запуск чи довіру до видавця. Установники зберігають профілі й секрети та не реєструють MCP-клієнти під час встановлення.
