## Встановлення

Завантажте архів для вашої ОС та процесора з GitHub Releases і розпакуйте його в постійне місце. Не запускайте програму прямо з архіву чи тимчасової папки.

- macOS 13 Ventura або новіша: перенесіть MCP Connect.app у Applications. Apple Silicon — arm64, Intel — amd64.
- Windows: збережіть папку програми, наприклад у вашій папці програм користувача. Більшість ПК — amd64; ARM-пристрої — arm64.
- Linux: розпакуйте архів, дайте mcp-connect право виконання й запустіть у графічній desktop-сесії. Потрібні OpenGL/X11-сумісні бібліотеки, D-Bus та розблокований Secret Service (наприклад GNOME Keyring або KWallet із Secret Service).

Go, Zig, Python чи Node для самої утиліти не потрібні. Відповідний AI-клієнт має бути встановлений окремо; для реєстрації Claude Code/Codex потрібен його підтримуваний CLI. Настільні програми та їхні клієнтські CLI мають власні умови доступності й підтримки ОС.

## Підключення

1. Введіть назву й кінцеву HTTPS-адресу MCP-сервера.
2. Виберіть логін/пароль, Bearer token або API key — сервер має підтримувати цей спосіб.
3. Введіть облікові дані локально. Для Bearer введіть тільки токен без префікса Bearer. Для API key виберіть заголовок, який очікує сервер.
4. Виберіть клієнти, натисніть Test Connection, потім Save & Connect.
5. Перезапустіть клієнти й почніть новий чат. Плашка статусу відкриває налаштування або підказку для відповідного клієнта.

ChatGPT Desktop використовує локальний плагін у чаті з локальним виконанням. Звичайний браузерний чи мобільний чат не підхоплює локальний адаптер автоматично. Claude Desktop і Claude Code мають окремі налаштування.

## Облікові дані

Секрети зберігаються в macOS Keychain, Windows Credential Manager або Linux Secret Service. У файлах конфігурації AI-клієнтів є лише шлях до адаптера та ID підключення. Немає відкритого текстового сховища як запасного варіанта.

Для сумісності ОС повний запис секрету разом із прив'язкою до сервера обмежений 2560 байтами. Дуже довгі токени можуть не вміститися. OAuth-вхід і автоматичне оновлення токенів не реалізовані.

Порожні поля повторно використовують збережені дані тільки за незмінної адреси, способу й API-заголовка. Для старого запису без прив'язки до сервера введіть дані заново й збережіть. На Mac дозвіл Keychain стосується конкретної програми/підпису; нова непідписана видавцем збірка може попросити дозвіл знову.

Синій Configured означає локальне налаштування, зелений Verified — результат останньої явної перевірки. Це не постійний моніторинг. Test Connection перевіряє handshake та перелік інструментів, не викликаючи бізнес-інструменти.

## Оновлення й видалення

Профілі та секрети лежать окремо від програми. Після зміни шляху використайте Save & Connect для виправлення реєстрацій. Disconnect прибирає власні реєстрації й залишає секрет; Delete також прибирає профіль і секрет. Перезапустіть MCP-клієнти, щоб завершити вже відкриті сесії. Перед видаленням програми відключіть її підключення.

## Межі попереднього випуску

macOS-збірки мають локальний ad-hoc підпис; Developer ID та notarization відсутні. Windows-збірки не мають підпису видавця. ОС може показати попередження про невідомого видавця. Тести в CI не замінюють перевірку всіх desktop-оточень і версій сторонніх AI-клієнтів.

Для інших користувачів використовуйте окремі облікові записи з мінімальними правами. Утиліта не обмежує набір інструментів сервера й не змінює його права доступу. Не публікуйте облікові дані, локальні профілі чи бізнес-дані в GitHub Issues.
