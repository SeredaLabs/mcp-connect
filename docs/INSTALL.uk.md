### 🔌 Ваші MCP-сервери у програмах, якими ви користуєтесь.

MCP Connect — компактна настільна утиліта для підключення AI-клієнтів до HTTPS MCP-серверів. Введіть адресу сервера й облікові дані, виберіть програми та підключіться. Секрети залишаються в захищеному сховищі ОС; клієнт запускає адаптер за потреби.

**Користувачам:** [⬇ Завантажити](https://seredalabs.github.io/mcp-connect/) · [Підключення](#підключення) · [Авторизація](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/AUTHENTICATION.uk.md) · [Оновлення](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/UPDATES.uk.md)

Сторінка визначає ОС і підбирає установник, якщо браузер повідомляє архітектуру. Якщо процесор не визначено, виберіть його один раз. Портативні архіви також доступні.

**Про проєкт:** [Безпека](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/SECURITY.uk.md) · [Збирання з коду](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/BUILD.uk.md) · [Архітектура інтеграцій](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/INTEGRATIONS.uk.md)

<a id="можливості"></a>

## ✨ Можливості

- **Одне компактне вікно.** Профілі, авторизація й статуси клієнтів поруч.
- **Три способи авторизації.** Логін і пароль, Bearer token або API key.
- **Системне сховище секретів.** macOS Keychain, Windows Credential Manager або Linux Secret Service.
- **Без фонової служби.** Адаптер запускається за потреби. Для готової утиліти не потрібні Go, Node чи Python.

<a id="встановлення"></a>

## 📦 Встановлення

Відкрийте [сторінку завантаження](https://seredalabs.github.io/mcp-connect/): вона підбере ОС і, якщо можливо, процесор. Портативні архіви та [всі пакунки випуску](https://github.com/SeredaLabs/mcp-connect/releases) також доступні.

| ОС | Установник | Куди встановлює |
|---|---|---|
| macOS 13+ | `-installer.pkg` | `/Applications/MCP Connect.app` |
| Windows | `-setup.exe` | `%LOCALAPPDATA%\Programs\MCP Connect` |
| Ubuntu 24.04 та сумісні системи | `.deb` | `/opt/mcp-connect`, ярлик у меню програм |

- **macOS:** відкрийте `.pkg` і пройдіть стандартні кроки встановлення. Потрібне підтвердження адміністратора. Apple Silicon — arm64, Intel — amd64.
- **Windows:** відкрийте `-setup.exe`. Програма встановлюється для поточного користувача без прав адміністратора, додає ярлик у меню «Пуск» і пункт видалення в налаштуваннях Windows. Ярлик на робочому столі — за бажанням. Більшість Intel/AMD ПК — amd64; ARM-пристрої — arm64.
- **Linux:** відкрийте `.deb` через менеджер програм або виконайте `sudo apt install ./mcp-connect-linux-amd64.deb`. Для ARM виберіть файл arm64. Пакунок додає іконку, пункт у меню й команду `mcp-connect`. Для інших дистрибутивів доступний `.tar.gz` за наявності сумісних бібліотек.

Установники копіюють програму та ярлики, але не вводять облікові дані й не налаштовують MCP-клієнти. Підключення створюється після запуску утиліти. Після переходу з архівної копії відкрийте встановлену програму й натисніть **Save & Apply**, щоб оновити шлях до адаптера.

Для ручного встановлення розпакуйте архів у постійне місце. Не запускайте програму з архіву чи тимчасової папки.

Відповідні AI-клієнти встановлюються окремо й мають власні вимоги до ОС та доступності. Для реєстрації Codex і Claude Code потрібен підтримуваний CLI.


### 🧳 Портативні версії

Архіви мають назви `mcp-connect-<платформа>-<архітектура>-portable.zip` (macOS/Windows) або `-portable.tar.gz` (Linux). Вибирайте `portable` для запуску без установника; `.pkg`, `-setup.exe` чи `.deb` — для стандартного встановлення. У назвах файлів `darwin` означає macOS.

Портативність стосується файлів програми: профілі та облікові дані залишаються в папці налаштувань і захищеному сховищі цієї ОС. Вони не переносяться разом з архівом чи флешкою. Перед підключенням клієнтів збережіть розпаковану програму в постійному місці.

### 🖼️ Іконка й ярлик Linux

У macOS іконка вбудована в `.app`, у Windows — в `.exe`. Linux-установник `.deb` додає іконку та ярлик автоматично. Якщо використовуєте **архів `.tar.gz`**, виконайте з розпакованої папки:

```sh
install -Dm755 mcp-connect "$HOME/.local/bin/mcp-connect"
install -Dm644 icon.png "$HOME/.local/share/icons/hicolor/512x512/apps/mcp-connect.png"
install -Dm644 mcp-connect.desktop "$HOME/.local/share/applications/mcp-connect.desktop"
```

Папка `~/.local/bin` має бути в `PATH` графічного сеансу. Встановіть ярлик **до** налаштування підключень, щоб клієнти зберегли постійний шлях до адаптера. Іконка звичайного Linux-виконуваного файла у файловому менеджері залежить від оточення; логотип відображається в ярлику та вікні програми.

<a id="підключення"></a>

## 🔌 Підключення

1. Відкрийте **MCP Connect** із постійного місця встановлення.
2. Введіть назву підключення й кінцеву **HTTPS-адресу MCP-сервера**.
3. Виберіть спосіб авторизації, який підтримує сервер, і введіть облікові дані локально.
4. Виберіть встановлені клієнти, натисніть **Test Server**, потім **Save & Apply**.
5. Перезапустіть клієнти й почніть новий чат.

**Test Server** перевіряє узгодження MCP-з'єднання та перелік інструментів, не викликаючи бізнес-інструменти. Плашка статусу клієнта відкриває його налаштування або інструкцію з підключення. Кнопка **How to connect** біля **Connect your apps** відкриває інструкцію з підключення. Наведіть курсор на клієнта або спосіб авторизації, щоб побачити підказку про охоплення, наступні кроки та облікові дані. Кнопка **ⓘ** біля назви відкриває **About MCP Connect**: версію, автора, документацію й поради з обслуговування утиліти.

<a id="клієнти"></a>

## 🤖 Підтримувані клієнти

| Постачальник | Клієнт | Підключення |
|---|---|---|
| OpenAI | Codex | Локальна реєстрація MCP через встановлений CLI |
| OpenAI | ChatGPT Desktop | Локальний плагін у чаті з локальним виконанням |
| Anthropic | Claude Desktop | Локальна конфігурація настільної програми |
| Anthropic | Claude Code | Локальна реєстрація MCP через встановлений CLI |

AI-клієнти встановлюються окремо. CLI, встановлений через npm, може потребувати Node, хоча сам MCP Connect не потребує такого середовища. Для інтеграції ChatGPT потрібен сумісний вбудований або встановлений Codex CLI. Локальний плагін автоматично не з'являється у звичайному браузерному чи мобільному чаті. Claude Desktop і Claude Code налаштовуються окремо.

Галочки визначають, де зареєструвати сервер. Вони набувають чинності лише після **Save & Apply**; до цього видно **Will be added / Will be removed**. Статус **Registered** означає наявність реєстрації, а **Verified** — результат останньої перевірки сервера. Зміна лише клієнтів або назви профілю не звертається до сервера чи сховища секретів. Новий endpoint і зміни облікових даних перевіряються перед збереженням.

Якщо налаштування одного клієнта не вдалося, успішні дії зберігаються. **Retry** біля клієнта повторює лише його дію; **Details** показує результати та пояснення помилок. При переході між профілями чи закритті програма пропонує підтвердити відкидання незбережених правок.

Codex зберігає пряму реєстрацію для локального застосунку, CLI та IDE. Плагін ChatGPT потребує локального виконання й також може з'явитися в Codex. Якщо в сесії Codex видно обидва записи, увімкніть лише один. Claude Code налаштовується для всіх проєктів користувача; JSON-інтеграція Claude Desktop працює в локальному чаті, не в Cowork чи claude.ai.

**Disconnect** блокує нові запуски адаптера до очищення клієнтських конфігурацій. Якщо очищення не вдалося, профіль залишається вимкненим, а дію можна повторити. Уже відкриті сесії потрібно закрити. Зняття всіх галочок у збереженому профілі та **Save & Apply** також вимикає його.

## 💻 Платформи

| ОС | Процесор | Пакунок |

<a id="індикатори"></a>

## 🚦 Значення індикаторів

| Індикатор | Значення |
|---|---|
| **Registered** · синій | Локальна реєстрація існує; перезапустіть клієнт |
| **Verified** · зелений | Остання явна перевірка сервера успішна |
| **Test required** · жовтий | Налаштування змінилися або потребують перевірки |
| **Not registered** · сірий або жовтий | Прямої реєстрації немає; жовтий, якщо клієнта вибрано |
| **Via OpenAI plugin** · синій | Codex бачить спільний плагін без прямого запису |
| **Will be added / Will be removed** · жовтий | Вибір клієнта ще не застосовано |
| **Registered · will remove** · жовтий | Чинний запис не вибрано; застосування прибере його |
| **Repair needed** · жовтий | Запис указує на інший шлях програми; натисніть Save & Apply |
| **Disabled in client** · жовтий | Запис існує, але вимкнений у конфігурації клієнта |
| **Needs attention** · червоний | Остання дія клієнта не вдалася; відкрийте Details і натисніть Retry |
| **Check settings** · червоний | Конфігурацію не вдалося прочитати або виявлено чужий запис |
| **Cleanup needed** · жовтий | Профіль вимкнено, але запис клієнта залишився; повторіть очищення |
| **Disabled** · сірий | Профіль неактивний; нові запуски адаптера заблоковано |

Це результат останніх дій, а не постійний моніторинг. **Registered** не підтверджує, що клієнт уже завантажив інструменти, а **Verified** не засвідчує сумісність версії AI-клієнта. Після відключення перезапустіть клієнти, щоб завершити вже відкриті сесії адаптера.

<a id="облікові-дані"></a>

## 🔐 Облікові дані й безпека

Паролі, токени та API-ключі зберігаються в системному сховищі секретів. У конфігурації клієнтів є лише шлях до адаптера й ID підключення. Запасного зберігання відкритим текстом немає.

Секрети прив'язані до адреси сервера, способу авторизації та заголовка API-ключа. Зміна цих параметрів потребує повторного введення. Повний запис обмежений **2560 байтами** для сумісності з Windows. OAuth-вхід і автоматичне оновлення токенів не реалізовані. Докладніше — [авторизація](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/AUTHENTICATION.uk.md).

Використовуйте окремий серверний обліковий запис із мінімальними правами. Утиліта не змінює права на сервері й не обмежує дозволені вашому обліковому запису інструменти. Про вразливості повідомляйте приватно через [Security → Report a vulnerability](https://github.com/SeredaLabs/mcp-connect/security/advisories/new). Не публікуйте секрети, профілі чи бізнес-дані в Issues.

<a id="оновлення-й-видалення"></a>

## 🔄 Оновлення й видалення

Нова версія підсвічується кнопкою **Update · v…** у бічній панелі. Ручна перевірка: **ⓘ → About MCP Connect → Check for updates**. Також доступна команда `update`; [інструкція для всіх ОС](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/UPDATES.uk.md).

Профілі та секрети зберігаються окремо від програми; установники та видалення пакунків їх не прибирають. Перед оновленням закрийте утиліту й активні сесії MCP-клієнтів. У Windows видаліть програму через «Встановлені програми», у Linux — через менеджер пакунків (`sudo apt remove mcp-connect`), у macOS — приберіть `.app` з Applications після відключення інтеграцій. Після зміни її шляху натисніть **Save & Apply**, щоб оновити реєстрації. **Disconnect** спочатку вимикає профіль, потім прибирає реєстрації й залишає секрет; **Delete** також видаляє профіль і секрет. Перезапустіть клієнти для завершення вже відкритих сесій. Перед видаленням програми відключіть її підключення.

<a id="межі-попереднього-випуску"></a>

## 🧪 Межі попереднього випуску

Поточна версія **0.4.14 Preview** призначена для розробників і раннього тестування. Починаючи з версії 0.4.4, у пакуванні виправлено мінімальну версію macOS: 13.0. macOS-пакунки 0.4.3 фактично вимагали macOS 15; використовуйте виправлений випуск.

Нативний CI запускає unit- і контрактні тести, перевірки залежностей, збирання пакунків, оновлення встановленої 0.4.13 та видалення на Windows/Linux. Linux AMD64 також проходить перевірку гонок. Опис релізу містить посилання на підтверджений запуск і контрольні суми пакунків.

Перевірки нативного вікна використовують порожні тимчасові профілі. Linux працює з Xvfb/software OpenGL; графічне середовище macOS/Windows VM може бути недоступним або непідтвердженим — це окремий результат, а не успішний GUI-тест. Перевірки не засвідчують ручну роботу GUI на всіх платформах чи сумісність з усіма версіями AI-клієнтів. **Графічна підтримка Windows ARM64 залишається експериментальною.** Робота GUI на фізичному Intel Mac і macOS 13 також потребує підтвердження.

macOS-програма має ad-hoc підпис, але `.pkg` не має підпису Developer ID Installer чи нотаризації. Windows-програма й установник не мають підпису видавця. ОС може показувати попередження. Автоматичні перевірки не гарантують сумісності з усіма оточеннями й версіями AI-клієнтів. Контрольні суми файлів доступні в `SHA256SUMS.txt` відповідного випуску.
