### 🔌 Ваші MCP-сервери у програмах, якими ви користуєтесь.

MCP Connect — компактна настільна утиліта для підключення AI-клієнтів до HTTPS MCP-серверів. Введіть адресу сервера й облікові дані, виберіть програми та підключіться. Секрети залишаються в захищеному сховищі ОС; клієнт запускає адаптер за потреби.

**Користувачам:** [Завантажити](https://github.com/SeredaLabs/mcp-connect/releases) · [Підключення](#підключення) · [Авторизація](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/AUTHENTICATION.uk.md)

**Про проєкт:** [Безпека](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/SECURITY.uk.md) · [Збирання з коду](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/BUILD.uk.md)

<a id="можливості"></a>

## ✨ Можливості

- **Одне компактне вікно.** Профілі, авторизація й статуси клієнтів поруч.
- **Три способи авторизації.** Логін і пароль, Bearer token або API key.
- **Системне сховище секретів.** macOS Keychain, Windows Credential Manager або Linux Secret Service.
- **Без фонової служби.** Адаптер запускається за потреби. Для готової утиліти не потрібні Go, Node чи Python.

<a id="встановлення"></a>

## 📦 Встановлення

Завантажте установник для вашої ОС та процесора з [Releases](https://github.com/SeredaLabs/mcp-connect/releases). Архіви для ручного встановлення також залишаються доступними.

| ОС | Установник | Куди встановлює |
|---|---|---|
| macOS 13+ | `-installer.pkg` | `/Applications/MCP Connect.app` |
| Windows | `-setup.exe` | `%LOCALAPPDATA%\Programs\MCP Connect` |
| Ubuntu 24.04 та сумісні системи | `.deb` | `/opt/mcp-connect`, ярлик у меню програм |

- **macOS:** відкрийте `.pkg` і пройдіть стандартні кроки встановлення. Потрібне підтвердження адміністратора. Apple Silicon — arm64, Intel — amd64.
- **Windows:** відкрийте `-setup.exe`. Програма встановлюється для поточного користувача без прав адміністратора, додає ярлик у меню «Пуск» і пункт видалення в налаштуваннях Windows. Ярлик на робочому столі — за бажанням. Більшість Intel/AMD ПК — amd64; ARM-пристрої — arm64.
- **Linux:** відкрийте `.deb` через менеджер програм або виконайте `sudo apt install ./mcp-connect-linux-amd64.deb`. Для ARM виберіть файл arm64. Пакунок додає іконку, пункт у меню й команду `mcp-connect`. Для інших дистрибутивів доступний `.tar.gz` за наявності сумісних бібліотек.

Установники копіюють програму та ярлики, але не вводять облікові дані й не налаштовують MCP-клієнти. Підключення створюється після запуску утиліти. Після переходу з архівної копії відкрийте встановлену програму й натисніть **Save & Connect**, щоб оновити шлях до адаптера.

Для ручного встановлення розпакуйте архів у постійне місце. Не запускайте програму з архіву чи тимчасової папки.

Відповідні AI-клієнти встановлюються окремо й мають власні вимоги до ОС та доступності. Для реєстрації Codex і Claude Code потрібен підтримуваний CLI.


### 🧳 Портативні версії

Архіви мають назви `mcp-connect-<платформа>-<архітектура>-portable.zip` (macOS/Windows) або `-portable.tar.gz` (Linux). Вибирайте `portable` для запуску без установника; `.pkg`, `-setup.exe` чи `.deb` — для стандартного встановлення. У назвах файлів `darwin` означає macOS.

Портативність стосується файлів програми: профілі та облікові дані залишаються в папці налаштувань і захищеному сховищі цієї ОС. Вони не переносяться разом з архівом чи флешкою. Перед підключенням клієнтів збережіть розпаковану програму в постійному місці.

### 🖼️ Іконка й ярлик Linux

У macOS іконка вбудована в `.app`, у Windows — в `.exe`. Linux-установник `.deb` додає іконку та ярлик автоматично. Якщо використовуєте **архів `.tar.gz`**, виконайте з розпакованої папки:

```sh
install -Dm755 mcp-connect "$HOME/.local/bin/mcp-connect"
install -Dm644 icon.png "$HOME/.local/share/icons/hicolor/512x512/apps/mcp-connect.png"
install -Dm644 mcp-connect.desktop "$HOME/.local/share/applications/mcp-connect.desktop"
```

Папка `~/.local/bin` має бути в `PATH` графічного сеансу. Встановіть ярлик **до** налаштування підключень, щоб клієнти зберегли постійний шлях до адаптера. Іконка звичайного Linux-виконуваного файла у файловому менеджері залежить від оточення; логотип відображається в ярлику та вікні програми.

<a id="підключення"></a>

## 🔌 Підключення

1. Відкрийте **MCP Connect** із постійного місця встановлення.
2. Введіть назву підключення й кінцеву **HTTPS-адресу MCP-сервера**.
3. Виберіть спосіб авторизації, який підтримує сервер, і введіть облікові дані локально.
4. Виберіть встановлені клієнти, натисніть **Test Connection**, потім **Save & Connect**.
5. Перезапустіть клієнти й почніть новий чат.

**Test Connection** перевіряє узгодження MCP-з'єднання та перелік інструментів, не викликаючи бізнес-інструменти. Плашка статусу клієнта відкриває його налаштування або інструкцію з підключення. Кнопка **How to connect** біля **Connect your apps** пояснює підключення клієнтів. Кнопка **ⓘ** біля назви відкриває **About MCP Connect**: версію, автора, документацію й поради з обслуговування утиліти.

|---|---|---|
| OpenAI | Codex | Локальна реєстрація MCP через встановлений CLI |

<a id="платформи"></a>

## 💻 Платформи

| ОС | Процесор | Пакунок |
|---|---|---|
| macOS 13+ | Apple Silicon / Intel | `.pkg` або `.app` в ZIP |
| Windows | AMD64 / ARM64 | `-setup.exe` або ZIP |
| Linux | AMD64 / ARM64 | `.deb` або `.tar.gz` |

Потрібні графічний сеанс і драйвери з підтримкою OpenGL 2.1. Linux-пакунки орієнтовані на Ubuntu 24.04: потрібні бібліотеки OpenGL/Wayland/X11, D-Bus і розблокований Secret Service, наприклад GNOME Keyring. Інші дистрибутиви можуть потребувати додаткових бібліотек.

<a id="індикатори"></a>

## 🚦 Значення індикаторів

| Індикатор | Значення |
|---|---|
| **Configured** · синій | Локальну реєстрацію збережено |
| **Verified** · зелений | Остання явна перевірка сервера успішна |
| **Test required** · жовтий | Налаштування змінилися або потребують перевірки |
| **Disabled / Not configured** · сірий | Профіль або інтеграція неактивні |

Це результат останніх дій, а не постійний моніторинг. Після відключення перезапустіть клієнти, щоб завершити вже відкриті сесії адаптера.

<a id="облікові-дані"></a>

## 🔐 Облікові дані й безпека

Паролі, токени та API-ключі зберігаються в системному сховищі секретів. У конфігурації клієнтів є лише шлях до адаптера й ID підключення. Запасного зберігання відкритим текстом немає.

Секрети прив'язані до адреси сервера, способу авторизації та заголовка API-ключа. Зміна цих параметрів потребує повторного введення. Повний запис обмежений **2560 байтами** для сумісності з Windows. OAuth-вхід і автоматичне оновлення токенів не реалізовані. Докладніше — [авторизація](https://github.com/SeredaLabs/mcp-connect/blob/main/docs/AUTHENTICATION.uk.md).

Використовуйте окремий серверний обліковий запис із мінімальними правами. Утиліта не змінює права на сервері й не обмежує дозволені вашому обліковому запису інструменти. Про вразливості повідомляйте приватно через [Security → Report a vulnerability](https://github.com/SeredaLabs/mcp-connect/security/advisories/new). Не публікуйте секрети, профілі чи бізнес-дані в Issues.

<a id="оновлення-й-видалення"></a>

## 🔄 Оновлення й видалення

Профілі та секрети зберігаються окремо від програми; установники та видалення пакунків їх не прибирають. Перед оновленням закрийте утиліту й активні сесії MCP-клієнтів. У Windows видаліть програму через «Встановлені програми», у Linux — через менеджер пакунків (`sudo apt remove mcp-connect`), у macOS — приберіть `.app` з Applications після відключення інтеграцій. Після зміни її шляху натисніть **Save & Connect**, щоб оновити реєстрації. **Disconnect** прибирає реєстрації й залишає секрет; **Delete** також видаляє профіль і секрет. Перезапустіть клієнти для завершення вже відкритих сесій. Перед видаленням програми відключіть її підключення.

<a id="межі-попереднього-випуску"></a>

## 🧪 Межі попереднього випуску

Поточна версія **0.4.9 Preview** призначена для розробників і раннього тестування. Починаючи з версії 0.4.4, у пакуванні виправлено мінімальну версію macOS: 13.0. macOS-пакунки 0.4.3 фактично вимагали macOS 15; використовуйте виправлений випуск.

Інтерфейс Apple Silicon перевірено на фізичному Mac із macOS 14.4.1. Графічний запуск перевірено для обох Linux-архітектур і Windows AMD64; у Windows використано програмний OpenGL лише в CI, він не входить до пакунка. **Windows ARM64 залишається експериментальним:** адаптер і сховище секретів пройшли перевірки, але графічний запуск не підтверджено. Також не підтверджено інтерфейс на фізичному Intel Mac та запуск на macOS 13.

macOS-програма має ad-hoc підпис, але `.pkg` не має підпису Developer ID Installer чи нотаризації. Windows-програма й установник не мають підпису видавця. ОС може показувати попередження. Автоматичні перевірки не гарантують сумісності з усіма оточеннями й версіями AI-клієнтів. Контрольні суми файлів доступні в `SHA256SUMS.txt` відповідного випуску.
